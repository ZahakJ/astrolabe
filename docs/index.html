[[ Astrolabe ]]

A self-hosted, open-source alternative to Obsidian, with publishing built in.

Coming from Obsidian

  • Your vault opens as it is: wikilinks, embeds, callouts, properties, highlights and footnotes are read as Obsidian writes them, and the folder keeps working in Obsidian.
  • Publishing is built in. Mark a note publish: true and it is on your blog, with RSS, comments and scheduled posts. No subscription.
  • No sync service to pay for. The server holds the vault; browsers, the desktop app and the Android app all open the same notes, and history is backed up to a git remote you own.
  • A web app, so any device with a browser can reach your notes, at home or behind your own domain.
  • Open source, under the MIT license.

The library

Books and courses, read in order

Right-click a folder and put it on the shelf as a book, a course or a series. Its subfolders become chapters and its published notes lessons. Readers get a contents list, their place kept, and the arrow keys to move between lessons.

The graph

Graph view

Every wikilink as an edge. Colour notes by folder, tag or link count, hide unlinked notes, find a note, and adjust the forces. It stays responsive with thousands of notes.

The blog

Blog mode

A masthead, a topic bar built from your tags, a home page of posts and a shelf for the library. RSS, a sitemap, meta tags rendered on the server, and reader comments that wait for your approval.

Notes to self

Annotations that leave the note alone

Select a passage and write a note on it. Annotations are stored beside the vault and anchored to the quoted text, so they survive edits to the note. Keep them private or show them to readers.

The editor

The editor

CodeMirror 6 with live preview, wikilinks with autocomplete, backlinks, transclusions, callouts, KaTeX, a command palette and vim mode. A PDF and EPUB reader whose highlights become cited notes. Right-to-left text (Arabic, Persian, Hebrew) edits natively beside English.

Install

The server needs Node 24 or later. Then open http://localhost:6801. Notes stay ordinary files in the folder.

# run from source
git clone https://github.com/ZahakJ/astrolabe.git && cd astrolabe && npm install && npm start
# use an existing folder of notes
ASTROLABE_VAULT=~/notes npm start
# set an admin password before publishing
npm run hash-password   # → ADMIN_PASSWORD_HASH in .env
